# Roadmap

## Month 1 – MVP CLI

- Interactive CLI accepting natural language prompts
- AI generates Playwright code
- Local execution only
- Config file for custom selectors
- Central AI server (stateless)
- Open-source release on GitHub

## Month 2 – Early SaaS

- REST API backend in Go
- PostgreSQL to store test results
- MongoDB for configs
- Short-term memory per user (last N interactions)
- Optional BYO AI key
- Basic web UI (login, create test, run test, view results)

## Month 3 – Stable SaaS

- Full web frontend (React/Next.js)
- Multi-user support and authentication
- Long-term user memory (preferences, selectors)
- Vector DB for RAG with user/company docs (e.g., specs, QA guides, Figma exports)
- Metrics dashboard and historical reporting
- Free tier and paid tiers with advanced features
- Improved AI prompts for consistency and reliability
