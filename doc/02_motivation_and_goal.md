
# Motivation and Goal

## Personal Goals

- Improve **backend skills** (Go, concurrency, interfaces).  
- Gain expertise in **AI integration** (LLMs, prompt engineering, retrieval-augmented generation).  
- Develop **DevOps experience** (Docker, Kubernetes, CI/CD pipelines).  
- Expand **frontend knowledge** (React, Next.js, TypeScript, Tailwind).  
- Build a **portfolio project** showcasing full-stack, AI, and SaaS skills.

## Problem Statement

- Small and medium-sized teams often **lack QA or SDE resources**.
- Manual testing is time-consuming and error-prone:
  - PMs check user flows like message scheduling.
  - Designers compare UI with Figma files manually.
  - Support staff follow long UAT checklists.
  
## Solution

- Allow **non-technical users to write tests in natural language**.
- AI generates **Playwright tests** for E2E, UI validation, and basic performance metrics.
- Users get **readable reports** with pass/fail results and error details.
- CLI MVP initially; SaaS version with cloud execution, memory, RAG, and dashboards later.
